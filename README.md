\# DSI-ESMDA



A simple Python project for data-space inversion using ensemble smoother

with multiple data assimilation.



The project currently works with CSV reservoir simulation files.



\## Main workflow



1\. Read the prior ensemble from CSV files.

2\. Read a complete truth model from CSV.

3\. Select observation times and add measurement noise.

4\. Run ES-MDA.

5\. Plot prior, posterior, truth, and observations.
